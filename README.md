# IT342-Castillo-SearchnSnip

## Project Overview
Searchn’Snip is a service based e-commerce platform that displays available barbershops near the customer's area. This platform also provides a way for barbers to display their barbershops to the customers, complete with features that let barbers upload a list of haircuts that can be chosen by customers in advance. This platform uses Spring Boot as the backend, React as the frontend web application, and an Android mobile app to provide seamless integration between devices.

## Technologies Used
- **Backend**: Java, Spring Boot, Spring Security, PostgreSQL
- **Web Frontend**: React
- **Mobile**: Android (Kotlin)

## Getting Started

### Backend
```bash
# Navigate to the backend directory
cd backend

# Compile and run the application
./mvnw spring-boot:run
```

### Web Frontend
```bash
# Navigate to the web directory
cd web

# Start the development server
npm start
```

### Mobile
- Open the project in Android Studio
- Build and run on an emulator or physical device

## Features
- Browse barbershops
- Book appointments
- Manage profile
- Shop management for barbers
